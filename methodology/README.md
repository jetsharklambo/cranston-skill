# Methodology (phase 4 placeholder)

discovery taxonomy with probe recipes, the 17-question priority-of-needs
interview, the 20-entry failure-mode audit library, and the doctrine
template — currently lives in the design blueprint (a separate, not-yet-published
document; sections 3, 4 and 7).

Phase 4 splits it into skill-consumable reference files here, so an agent
can run the onboarding conversationally and generate `services.json` +
`doctrine.md` for the admin to review.
